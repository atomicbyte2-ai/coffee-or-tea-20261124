# One Letter: Coffee or Tea

Entry for the make.fun bounty **"One Letter: Coffee or Tea"** — a single-letter
answer to the eternal question: coffee or tea?

The entry is one character: **A** — coffee. The classic developer drink, the
choice a tired senior engineer would defend. Written to `/output/entry.txt`
with no newline, no explanation, no punctuation.
